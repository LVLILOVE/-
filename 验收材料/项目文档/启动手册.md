## 1. 方式 A：单端口启动（推荐，最简）

**前端页面与 API 都由 8000 端口提供**（前端构建产物已内置在 `static/`）。

```bash
# 0) 定义解释器变量（每次新开终端执行一次）
PY="C:/Users/Administrator/WorkBuddy/2026-08-26-14-15-18/cat-isle-backend/.venv/Scripts/python.exe"

# 1) 进入后端目录（仓库版）
cd "C:/Users/Administrator/WorkBuddy/2026-08-26-14-15-18/-/cat-isle-backend"

# 2) 首次准备：确认 .env 存在（不存在则创建；请修改 JWT_SECRET 与 ADMIN_PASSWORD）
#    已有 .env（服务当前使用的这份已配好）则跳过
ls .env || cp .env.example .env

# 3) 初始化数据库 + 占位数据（幂等，可重复执行；不想要占位数据可用 $PY -m app.seed）
"$PY" -m app.seed_demo

# 4) 启动服务（生产必须 --workers 1：内嵌定时任务，多 worker 会重复执行）
"$PY" -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

> 首次使用且「工作区版」venv 不存在时的替代（只需一次）：
> 用系统 Python 创建仓库版 venv 并安装依赖：
> ```bash
> python -m venv "C:/Users/Administrator/WorkBuddy/2026-08-26-14-15-18/-/cat-isle-backend/.venv"
> "C:/Users/Administrator/WorkBuddy/2026-08-26-14-15-18/-/cat-isle-backend/.venv/Scripts/pip.exe" install -r requirements.txt
> # 然后把上面 $PY 指向仓库版 venv：.../-/cat-isle-backend/.venv/Scripts/python.exe
> ```

访问：
- 前台首页：http://127.0.0.1:8000
- 后台管理：http://127.0.0.1:8000/admin（账号：`.env` 中的 ADMIN_USERNAME / ADMIN_PASSWORD，当前密码见 .env）
- API 文档：http://127.0.0.1:8000/docs

journalctl -u catisle -f

## 5. 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示"找不到路径" | 使用本文档**绝对路径**（见 §0），不要用相对路径 `cd catisle-backend` |
| 端口被占用启动失败 | 按 §4「停止」命令清理后重启 |
| 忘记管理员密码 | 改 `.env` 的 ADMIN_PASSWORD 后重启仅对新初始化生效；已存在的管理员需手动改库：`sqlite3 catisle.db "UPDATE admin_user SET password_hash='<bcrypt哈希>';"`（哈希可用 `$PY -c "from app.core.security import hash_password; print(hash_password('新密码'))"` 生成） |
| 前端页面是旧版本 | 重新执行 §4「更新前端产物」 |
| 需要重置数据库 | 停止服务 → 删除 `catisle.db` → `"$PY" -m app.seed_demo` → 启动 |

## 6. 让网站被访问（局域网 / 公网临时分享）

### 6.1 局域网访问（同一 WiFi 内，配置一次即可）

```bash
# 1) 服务绑定 0.0.0.0（默认 127.0.0.1 只能本机访问）
cd "C:/Users/Administrator/WorkBuddy/2026-08-26-14-15-18/-/cat-isle-backend"
PY="C:/Users/Administrator/WorkBuddy/2026-08-26-14-15-18/cat-isle-backend/.venv/Scripts/python.exe"
"$PY" -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1

# 2) 放行 Windows 防火墙 8000 端口（一次即可，需管理员权限的终端）
netsh advfirewall firewall add rule name="CatIsle-Web-8000" dir=in action=allow protocol=TCP localport=8000

# 3) 查看本机局域网 IP（对方访问 http://<该IP>:8000）
"$PY" -c "import socket; s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM); s.connect(('8.8.8.8',80)); print(s.getsockname()[0]); s.close()"
```

### 6.2 公网访问（任何网络都能打开，临时方案 · 无需注册）

使用 **pinggy** 免费 SSH 隧道，把 8000 端口映射为公网网址：

```bash
ssh -p 443 -R0:localhost:8000 a.pinggy.io
```

- 连接后终端会打印公网地址（形如 `https://xxxx.free.pinggy.net`），发给对方即可访问
- **免费版隧道 60 分钟过期**：过期后重新执行上面的 ssh 命令（地址会重新分配）
- 隧道依赖该 ssh 进程保持运行；本机必须同时跑着后端服务
- 备选：localhost.run（`ssh -R 80:localhost:8000 nokey@localhost.run`），国内连通性不如 pinggy 稳定

### 6.3 安全提醒

- 暴露到局域网/公网后，**后台管理页（/admin）同样可被访问**，请使用强密码（当前密码见 .env）
- 演示结束后建议恢复本机绑定：`--host 127.0.0.1`
- 长期对外运营请走正式上线（§7），勿依赖临时隧道
