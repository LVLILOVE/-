## 三、项目代码说明

### 后端 backend/（FastAPI + SQLAlchemy + SQLite）
- `app/`：主程序（models 9 张表 / routers 前台+后台 29 个接口 / services 预约押金 / core 配置与安全）
- `tests/`：pytest 28 项用例（预约/押金/领养/问答/鉴权等）
- `scripts/`：初始化与端到端验证脚本
- `requirements.txt` / `.env.example`：依赖与环境变量模板

### 前端 frontend/（React 19 + Vite + Tailwind v4）
- `src/pages/`：前台 8 页 + 后台 8 模块
- `src/components/`：公共组件（含猫屿小助手）
- `public/`：本地图片资源（随构建入库）
- `package.json` / `vite.config.ts`：工程配置

### 部署 deploy/
- nginx / systemd / 备份脚本 / 上线检查清单

## 四、数据库脚本说明

| 文件 | 内容 | 用法 |
| --- | --- | --- |
| `catisle_schema.sql` | 9 张表完整建表语句（admin_user/cats/menu_items/reservations/adoptions/adoption_notes/qa/store_settings/slot_settings + 索引/约束） | `sqlite3 catisle.db < catisle_schema.sql` |
| `catisle_seed_data.sql` | 种子数据 24 行（管理员/4 时段/门店配置/6 只猫/10 项菜单/演示问答） | `sqlite3 catisle.db < catisle_seed_data.sql` |

> 已验证：用以上两脚本可从零重建出完整可运行的开发数据库（9 表 24 行）。

## 五、运行方式（简要）

```bash
# 单端口启动（前端产物内置 static/）
cd cat-isle-backend
python -m venv .venv && pip install -r requirements.txt
python -m app.seed_demo          # 初始化 + 占位数据
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
# 访问 http://127.0.0.1:8000 ｜ 后台 /admin
```
> 详细命令见 `项目文档/启动手册.md`
