# 猫屿 CAT ISLE · 上线检查清单

> 服务器与备案域名就绪后，按此清单逐项执行与打勾。检查人/日期：____

## 一、服务器准备

- [ ] 服务器已购买（Linux，建议 Ubuntu 22.04+，2C2G 起步）
- [ ] 域名已购买并完成 ICP 备案（`catisle.example.com` 替换为真实域名）
- [ ] DNS 解析生效（`dig 域名` 返回服务器 IP）
- [ ] 服务器安全组/防火墙放行 80/443

## 二、代码部署

- [ ] 拉取代码到 `/opt/catisle`：`git clone git@github.com:LVLILOVE/-.git catisle`
- [ ] 创建虚拟环境并安装依赖：`python3 -m venv .venv && .venv/bin/pip install -r cat-isle-backend/requirements.txt`
- [ ] 配置 `.env`：`cp .env.example .env`，修改 `JWT_SECRET`（强随机）、`ADMIN_PASSWORD`（强密码）
- [ ] 前端构建产物就位：`cat-isle-backend/static/` 已含 dist 内容（或部署机重新 build）
- [ ] 后端可访问性验证：`curl http://127.0.0.1:8000/api/store` 返回 code=0

## 三、服务与反代

- [ ] systemd 服务安装：`cp deploy/catisle.service /etc/systemd/system/ && systemctl enable --now catisle`
- [ ] 服务状态：`systemctl status catisle` 显示 active（running），`journalctl -u catisle` 无异常
- [ ] **确认单 worker**：`ps aux | grep uvicorn` 仅 1 个 worker 进程（定时任务防重复）
- [ ] Nginx 配置：`cp deploy/nginx.conf /etc/nginx/conf.d/catisle.conf`（替换域名）→ `nginx -t` → `systemctl reload nginx`
- [ ] 未配置 HTTPS 时先验证 HTTP 访问；配置后强制跳转

## 四、HTTPS（正式上线必需）

- [ ] `sudo apt install certbot python3-certbot-nginx`
- [ ] `sudo certbot --nginx -d catisle.example.com` 签发成功
- [ ] 自动续期验证：`sudo certbot renew --dry-run` 通过

## 五、数据初始化

- [ ] 后端启动后自动建表 + 种子（4 时段 / 押金 2000 分 / 管理员）
- [ ] 登录后台（`/admin`），在「门店设置」填入：地址 / 电话 / 营业时间 / 押金金额 / 地图 iframe / **微信收款码图片**
- [ ] 在「猫咪管理」录入真实猫咪（名字/性格/故事/实拍照片/可领养标记）
- [ ] 在「餐单管理」录入真实菜单与价格
- [ ] 前端门店区/猫咪区/餐单区数据正确展示（真实素材替换占位图）
