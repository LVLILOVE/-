## 1. 项目概述

### 1.1 项目范围

| 子系统 | 内容 |
| --- | --- |
| 前台展示系统 | 首页（单页长滚动）、猫咪列表/详情、餐单、预约（含押金流程）、领养（含申请）、隐私政策 |
| 后台管理系统 | 管理员登录、仪表盘、猫咪/餐单/预约/领养管理、门店/时段设置（仅店主 1 账号） |
| 排除范围 | 会员体系、在线支付、多语言、小程序/App（PRD §1.3 已确认） |

### 1.2 技术栈（开发技术文档 §1）

- **后端**：FastAPI + SQLAlchemy 2.x + SQLite（WAL）+ APScheduler
- **前端**：React 18 + TypeScript + Vite + Tailwind CSS + React Router + Zustand + axios
- **部署**：单机 Uvicorn（--workers 1）+ Nginx 反代（M4）

### 1.3 已有基础（本轮开发起点）

| 资源 | 状态 |
| --- | --- |
| 文档四件套 | 已齐备（PRD / UIUX / 开发技术文档 / 数据库设计文档） |
| 后台管理原型 | `猫屿后台管理原型.html`（7 模块可交互） |
| 前台首页原型 | `猫屿官网首页原型.html`（首页 9 区块） |
| 后端骨架 | `cat-isle-backend/`（22 文件，语法通过，可运行最小闭环） |

## 3. M2 后端开发（FastAPI）

### 3.1 任务分解

| # | 任务 | 依据 | 说明 |
| --- | --- | --- | --- |
| B1 | 工程完善 | 数据库设计文档 §4 | 在 cat-isle-backend 骨架基础上补齐：建库脚本（DDL 全量 CHECK/索引/部分唯一索引/种子）；Alembic 迁移初始化 |

| B3 | 认证模块 | 开发技术文档 §6.1 | 登录（5 次锁定 15 分钟）/ me；JWT 有效期 7 天 |
| B4 | 前台接口 | 开发技术文档 §6.2 | cats / menu / slots / store / adopted-cats；预约 4 接口（提交/凭证/状态/取消）；领养提交；前台公开上传（scene=adoption） |
| B5 | 后台接口 | 开发技术文档 §6.3 | 猫咪/餐单 CRUD（软删除/上下线）；预约列表/押金核验/状态操作/余量总览；领养列表/详情/流转/回访；门店/时段配置；统计；后台上传（压缩） |
| B6 | 定时任务 | 开发技术文档 §8.3 | APScheduler：超时未支付/核验未通过超时 → 自动取消释放名额 |
| B7 | 并发与安全 | 开发技术文档 §8.1/§9 | 预约提交 BEGIN IMMEDIATE 防超卖；同手机号防重复；上传类型/大小校验 |

## 6. 开发规范

- **Git 分支**：`main`（可发布）/ `develop`（集成）/ `feature/*`；提交信息 `feat(模块): 描述`、`fix(模块): 描述`
- **后端**：分层 router/service/model/schema；统一响应 `{code,msg,data}`；金额全程"分"；时间用 `datetime.now()` 本地时间
- **前端**：组件化 + 路由懒加载；Token 全部走 Tailwind 主题变量；图标用 Lucide SVG（禁 emoji）
- **联调**：后端 Swagger 为准；前端 Vite 代理 `/api → localhost:8000`；环境变量 `VITE_API_BASE`
- **代码评审**：每个 feature 分支合并 develop 前过一遍验收清单（UIUX §10.2）
