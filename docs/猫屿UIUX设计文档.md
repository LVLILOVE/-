## 1. 设计概述

### 1.1 设计目标

为单店猫咖「猫屿 CAT ISLE」建立统一的视觉与交互语言，实现三个目标：

1. **品牌感知**：延续 PRD §1.2 的治愈系定位 —— 用极简视觉承载情感，卖"陪伴时光"而非服务
2. **转化闭环**：全站 4 处「立即预约」入口（吸顶导航 / Hero / 门店区 / 移动端底部栏），预约路径永不丢失
3. **可执行性**：所有设计决策（色值、字号、间距、断点、对比度）均有明确数值，开发无需猜测

### 1.2 设计原则（对齐 PRD §1.2）

| 原则 | 落地方式 |
| --- | --- |
| 治愈系叙事 | 文案短句分段、图片先行；空状态/成功态使用治愈文案（"都做完了，剩下的时间都是你的"） |
| 日式极简美学 | 米白打底 80%、暖棕 15%、点缀 5%；大量留白；单栏长滚动叙事 |
| 猫咪即主角 | 猫咪实拍是页面主体，卡片 hover 上浮突出照片；每只猫有独立档案 |
| 温暖但不松懈 | 视觉柔和，但交互效率不妥协：快捷键、焦点态、触控目标 ≥44px |

### 1.3 参考风格借鉴（MOCHA）

借鉴 catmocha.jp 的：单页长滚动叙事结构、居中大字号标题、米白暖色系、克制用色、猫咪档案情感化。**不复制**其图片、文案与具体排版。

## 2. 设计系统

### 2.1 色彩系统

#### 2.1.1 基础色板（暖咖治愈系）

| 角色 | 色值 | 用途 | 备注 |
| --- | --- | --- | --- |
| 奶油米白 | `#F7F2EA` | 页面主背景 | 占比 80% |
| 柔和米白 | `#FBF8F2` | 次级背景（输入框/分区底） | |
| 卡片白 | `#FFFFFF` | 卡片/导航底 | |
| 暖奶咖 | `#C89F7B` | 主色：Logo、选中态、进度 | |
| 深暖棕 | `#6B4F3F` | 正文文字 | 对比 6.69:1 ✓ |
| 次级棕 | `#8A6F5C` | 次级文字 | |
| 淡棕 | `#B5A08F` | 提示/占位文字 | 仅用于非关键信息 |
| 橘猫橙 | `#E8935F` | 强调色：激活下划线、装饰 | **禁止做白字按钮底色**（2.39:1） |

#### 2.1.2 按钮与语义色

| 角色 | 色值 | 用途 | 白字对比度 |
| --- | --- | --- | --- |
| 主按钮底 | `#A94A26` | 主 CTA（立即预约/提交） | 5.68:1 ✓ |
| 主按钮 hover | `#8F3D1F` | | 7.09:1 ✓ |
| 高优先级 | `#B4503E` | 逾期、错误、高风险 | 配浅底 `#F7E3E0` |
| 中优先级 | `#A9792C` | 待办、进行中 | 配浅底 `#FAEEDA` |
| 低优先级/成功 | `#5C7A3C` | 完成、已确认 | 配浅底 `#EAF3DE` |

#### 2.1.3 色彩使用规则

- 主背景上文字必须用 `#6B4F3F` 系，**不得用浅灰 `#B5A08F` 作为正文**
- 彩色语义（优先级/状态）永远配"文字或图标"双重指示，颜色不作唯一信号（无障碍 §9）
- 卡片统一白底 + `#EADFCF` 1px 描边，不使用投影以外的彩色底

### 2.2 字体系统

#### 2.2.1 字体栈

| 用途 | 字体 | 备注 |
| --- | --- | --- |
| 中文标题 | 思源黑体（Noto Sans SC）Heavy/Medium | 中文站首选 |
| 中文正文 | 思源黑体 Regular / 微软雅黑 | |
| 英文标题点缀 | Varela Round（候选 Nunito Sans Bold） | 仅用于英文 Slogan/Logo |
| 英文正文 | Nunito Sans | 柔和圆润，契合治愈系（ui-ux-pro-max Soft Rounded 建议） |
| 数字/代码 | Inter / 等宽 Consolas | 价格、单号 |

> 中文环境下圆体类（站酷快乐体等）可作为标题装饰，需注意商用授权；正式开发建议统一思源黑体保证可维护性。

#### 2.2.2 字号阶梯

| Token | 字号 | 行高 | 用途 |
| --- | --- | --- | --- |
| `--fs-xs` | 12px | 1.6 | 标签、辅助说明 |
| `--fs-sm` | 13-14px | 1.7 | 卡片描述、导航 |
| `--fs-base` | 15-16px | 1.8 | 正文 |
| `--fs-lg` | 18px | 1.7 | 区块强调文字 |
| `--fs-xl` | 22-26px | 1.6 | 页面标题（sec-title） |
| `--fs-hero` | clamp(28px, 5vw, 52px) | 1.5 | Hero Slogan |
| 字距 | 标题 2-6px；正文 1px | | 标题字距放大营造呼吸感 |

### 2.3 间距与栅格

- **基础网格 8px**：所有间距取 8 的倍数（4px 用于微调）
- 区块垂直留白：`padding: 84px 5vw`（移动端 56px）
- 内容容器：最大宽度 `1100px` 居中（导航/页脚同宽）
- 行宽：正文行宽 ≤640px，居中排版
- 导航元素间距 30px；卡片内边距 16-22px

### 2.4 圆角系统

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 8px | 输入框、小标签 |
| `--radius-md` | 12-14px | 卡片、悬浮横幅 |
| `--radius-lg` | 16-18px | 大卡片、图片容器 |
| `--radius-full` | 999px | 按钮、徽章、头像 |
| 规则 | **全站无直角**；图片圆角与容器一致 | |

### 2.5 图标规范

- 统一使用 **Lucide 线框图标**（viewBox 24×24），禁止 emoji 作为 UI 图标（ui-ux-pro-max 规则）
- 尺寸：导航/按钮内 18-20px；区块标题旁 22px；装饰 24px
- 线条粗细：1.5-2px；颜色继承文字色
- 所有图标按钮必须有 `aria-label` 与可见焦点态

### 2.6 阴影与层级

| 层级 | 阴影 | 用途 |
| --- | --- | --- |
| 悬浮 | `0 4px 16px rgba(107,79,63,.10)` | 悬浮横幅、移动端底部栏 |
| 上浮 | `0 8px 24px rgba(107,79,63,.10)` | 卡片 hover |
| 导航 | `0 2px 16px rgba(107,79,63,.06)` | 毛玻璃导航滚动态 |

## 3. 组件规范

### 3.1 顶部导航（PRD §4.1）

**结构**：Logo（左）+ 导航项 + CTA（右）｜ 移动端：汉堡 + 底部固定预约栏

**桌面端（>900px）**

| 属性 | 规范 |
| --- | --- |
| 位置 | `position: fixed; top:0; left:0; right:0; z-index:100` |
| 初始背景 | `rgba(247,242,234,0)`（透明） |
| 滚动 >200px | 白 `rgba(255,255,255,.86)` + `backdrop-filter: blur(14px)` + 底部 1px `#EADFCF` + 阴影，padding 收窄 14px→10px，过渡 300ms |
| Logo | 圆形 `#C89F7B` 底白字「猫」36px + 文字「猫屿」17px/600/字距3px + 英文「CAT ISLE」10px |
| 导航项 | 4 项：猫咪/餐单/预约/领养，14px `#6B4F3F`，间距 30px |
| 激活态 | 底部 2px `#E8935F` 下划线 + `font-weight:500` |
| hover | 文字色转 `#A97B50` |
| 焦点环 | `outline: 2px solid #E8935F; outline-offset: 4px` |
| CTA | 主按钮「立即预约」（见 3.2），`margin-left:auto` |

**移动端（≤900px）**
- 收起导航项为汉堡按钮（三横线，22×2px `#6B4F3F`）
- 汉堡展开菜单：白底、全宽、4 项纵向排列，**每项 min-height 44px**、下虚线分隔
- 汉堡按钮 `aria-expanded` 管理展开状态
- 页面底部固定「立即预约」主按钮（白 `.94` + blur，safe-area-inset 适配）

### 3.2 按钮

| 状态 | 主按钮 | 次按钮（ghost） |
| --- | --- | --- |
| 默认 | 底 `#A94A26` 白字 14px/500/字距2px，padding `10px 28px`，radius full | 透明底，字/描边 `#A94A26` 1.5px，同尺寸 |
| hover | 底 `#8F3D1F`，`translateY(-1px)`，200ms | 底 `#FDF0E7` |
| 禁用 | opacity .5，`cursor:not-allowed` | 同左 |
| 焦点 | `outline:2px solid #A94A26; outline-offset:3px` | 同左 |

- 所有可点击元素必须 `cursor:pointer`
- hover 变换只允许 color/opacity/translateY（**禁止 scale 导致布局抖动**）

### 3.3 卡片

**猫咪卡**（列表/预览）
- 白底 + `#EADFCF` 1px 描边 + radius 16 + `overflow:hidden`
- 图片高度 210px（比例 4:3），`object-fit:cover`
- 内容区 padding `16px 18px 20px`：名字 17px/600 + 性格标签（浅驼底胶囊 12px）+ 一句话故事 13px `#8A6F5C`
- hover：`translateY(-4px)` + 阴影上浮，250ms；整卡可点击（`cursor:pointer` + 焦点环）

**菜单卡**：白底 radius 14，居中排版，圆形图占位 64px，名称 14px + 价格 `#A94A26` 600

**安全须知卡**：白底 radius 14，padding 22，图标（Lucide SVG 22px）+ 标题 15px + 说明 13px

### 3.4 表单（预约/领养通用）

| 元素 | 规范 |
| --- | --- |
| 标签 | 12.5px/600 `#6B4F3F`，必填项加 `*`（`#A94A26`），label 与 input 关联 |
| 输入框 | padding `9px 12px`，13px，radius 8，背景 `#FBF8F2`，描边 `#EADFCF`，focus 描边 `#C89F7B` + 焦点环 |
| 校验 | **onBlur 即时校验**（ui-ux-pro-max ux 规范），错误描边 `#B4503E` + 错误文案 12px `#B4503E`（`aria-describedby` 关联） |
| 输入类型 | 手机号 `type="tel"` + `autocomplete="tel"` + pattern `1[3-9]\d{9}`；姓名 `autocomplete="name"`；日期 `type="date"` |
| 提交按钮 | 主按钮，提交中置灰 + "提交中…"；成功后跳转结果视图 |
| 隐私提示 | 表单下方 12px `#B5A08F`："信息仅用于预约/领养联系，详见隐私政策" |

### 3.5 悬浮横幅（右侧，桌面端）

- 定位：`fixed; right:16px; top:50% translateY(-50%); z-index:90`，纵向排列 gap 10px
- 卡片：白底 + 描边 + radius 12 + 阴影，宽 ≥86px，标题 12px/600 + 副文案
- 内容：新猫报道（→/cats）/ 领养成功（→/adopt）/ 周边上新（后台可配外链）
- 移动端隐藏（由底部预约栏替代）

### 3.6 页脚

- 背景 `#F1E8DA`，上描边 `#EADFCF`，padding `48px 5vw 40px`
- 4 栏：品牌（Logo+文案）/ 导航 / 社交（小红书/抖音/公众号，Simple Icons 官方 SVG）/ 信息（营业时间、隐私政策）
- 底部版权 12px `#B5A08F`，上虚线分隔

## 5. 预约流程 UI

押金流程共 5 个可视化状态（PRD §6.1 状态机 → UI 呈现）：

| 状态 | UI 呈现 |
| --- | --- |
| **待支付押金**（提交成功） | 成功提示（绿色勾 + "预约成功，名额已锁定"）→ **收款码卡片**（店主微信收款码图 + 押金金额 ¥20 大字 + "转账时备注手机号"提示）→ **2h 倒计时**（琥珀色，超时自动取消）→ **凭证表单**（转账单号 选填 / 转账人微信昵称 必填）+ 提交按钮 |
| **押金待核验** | 进度提示"凭证已提交，店主核验中…"（琥珀徽章）+ 凭证回显卡片 + "预计 24h 内核验" |
| **核验未通过** | 红色提示 + 店主填写的原因 + 「重新提交凭证」按钮 + 倒计时（限时重提） |
| **已确认** | 绿色成功卡片"预约已确认" + 到店日期/时段/人数回显 + "核验通过后店主会电话联系您" + 取消提示（已确认后取消请联系店主） |
| **已取消** | 灰色卡片 + 取消原因 + "名额已释放" + 重新预约按钮 |

**状态查询页**：输入手机号 + 单号 → 展示当前状态卡片（同上表对应状态）+ 最近操作时间线（提交/支付/核验/取消）。

**交互细节**：
- 提交按钮防重复：点击后置灰 + "提交中…"
- 倒计时到 0 自动刷新为"已取消"状态

## 6. 领养流程 UI

## 9. 无障碍规范

### 9.1 色彩对比度（WCAG AA）

| 组合 | 对比度 | 状态 |
| --- | --- | --- |
| 正文 `#6B4F3F` on `#F7F2EA` | 6.69:1 | ✓ |
| 主按钮白字 on `#A94A26` | 5.68:1 | ✓ |
| 主按钮白字 on hover `#8F3D1F` | 7.09:1 | ✓ |
| 次级文字 `#8A6F5C` on `#F7F2EA` | 4.6:1 | ✓ |
| `#B5A08F` 文字 | — | ⚠️ 仅限非关键提示（如版权、隐私脚注），不用于正文/按钮 |
| **禁用** | 白字 on `#E8935F` | ✗ 2.39:1，禁止 |

### 9.2 交互无障碍

- 所有可交互元素有可见焦点环（`outline:2px solid`，主色/按钮色，offset 3-4px），**不得移除 outline 而无替代**
- 键盘可到达全部功能（Tab 顺序=视觉顺序）；汉堡菜单支持 Esc 关闭
- 状态/优先级**不只用颜色区分**：逾期=红字+图标+文字；优先级=色点+文字标签

### 9.3 语义与表单

- 语义标签：`header/nav/main/section/footer`；标题层级 h1→h3 不跳级
- 所有图片有 `alt`（装饰性图片 `alt=""` + `aria-hidden`）
- 表单：label 关联 input；错误用 `aria-describedby` 关联错误文案；`aria-required` 标必填
- 输入类型与 autocomplete：手机 `tel`+`autocomplete="tel"`、姓名 `autocomplete="name"`、日期 `type="date"`
- 校验：onBlur 即时校验，不只提交时（ui-ux-pro-max ux 规范）
