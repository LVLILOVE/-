### 3.2 训练参数

| 参数 | 值 | 说明 |
|---|---|---|
| 训练/验证/测试划分 | **8 : 1 : 1（按时间先后）** | 🔒 按**序列**整体切分，不按样本切 |
| 损失函数 | **MSE** | 作用于**残差目标**（见 3.4 铁律 1） |
| 优化器 | **Adam** | 初始学习率 0.001 |

| 训练样本 / 验证样本 | **8,140 / 850** | 演示数据集上 |
| 最佳验证损失 | **0.4741** | —— |
| 训练耗时 | ⏱️ **45.26 s（CUDA）** / 80 s（CPU） | —— |
| 训练峰值显存 | ⏱️ **111 MB** | —— |
| 训练时机 | 📌 **纯预训练推理**，不提供在线重训 | 见 §14 |

### 3.3 序列分级与降级参数

| 参数 | 值 | 说明 |
|---|---|---|
| `L1_MIN_VALID_POINTS` | **90** | 有效历史点数阈值 |
| L1 | 本仓 × 商品有效历史 **≥ 90** | 走 LSTM 推理 |
| L2 | 本仓不足，但**同商品跨仓聚合 ≥ 90** | 商品级降级 + 按历史占比分摊 |
| L3 | 跨仓聚合仍 **< 90** | 🔒 **不输出数值预测**，只给历史均值 |
| `MIN_USABLE_SIGMA` | **0.5** | 退化序列过滤阈值（σ 过小的近常量序列不参与训练） |
| 有效点数口径 | **插值前**的原始非空点数 | 插值造出的点不算"有历史" |

### 3.4 🔒 五条算法设计铁律（改动前必读）

| # | 铁律 | 违反后果 |
|---|---|---|
| 1 | **学残差**：目标 = `(y − 移动平均基线)/σ`（`TARGET_RESIDUAL`） | 学绝对值会让预测塌回序列均值（实测 预测std/真值std = **0.26**） |
| 2 | **按序列切分**（`split_by_series`），不按样本切 | 同序列相邻两天近乎相同，按样本切**必然泄漏** |
| 3 | **退化序列过滤**：`MIN_USABLE_SIGMA = 0.5` | σ≈0.03 的近常量序列除完残差放大十倍，污染全局 loss |
| 4 | **营销节点保护**：`truncate_spikes(..., preserve_calendar=...)` | 无条件截断会削掉大促尖峰 —— 那是**唯一可学的业务信号** |
| 5 | **主指标只算 L1**：`levels_for_main=("L1",)` | L2 是规则的锅（实测 L2 MAPE ≈ 60%），混入会把 13.6% 变成 25.9% |

### 3.5 评测参数

| 参数 | 值 | 说明 |
|---|---|---|
| `backtest` | 🔒 **必须为 `True`** | 先砍掉末尾 horizon 天再评估，否则等于"看着答案出题" |
| 基线 | **移动平均** | 🔒 基线必须在**完全相同的预测点、相同序列集合**上计算 |
| 评估 horizon | **14**（默认导出口径） | `eval_report.py --horizon 14` |
| 等价性回归 | `verify_ep5_equiv.py` | 改造前后逐位 `np.array_equal`，全部 L1 序列 × 3 档步长 |

### 3.6 流水线五阶段与预算占比

| 阶段 | 键名 | 中文名 | 预算占比 |
|---|---|---|---|
| 1 | `validate` | 数据读取与校验 | 0.003 |
| 2 | `preprocess` | 预处理 · 缺失插值 + 异常尖峰截断 | 0.113 |
| 3 | `features` | 特征构建 + 序列分级 | 0.172 |
| 4 | `inference` | 批量模型推理 | **0.610**（最大） |
| 5 | `metrics` | 指标计算 | 0.102 |

> 🔒 五阶段常量前后端**逐项相等**（由 `verify_ep5.py` 断言）；
> 占比之和必须为 **1.0**，且 `inference` 必须最大（执行页时间轴宽度依据）。
> ⏱️ 实测 h=7 小样本：`3 / 70 / 54 / 119 / 13 ms`，合计 0.74 s。

### 3.7 两遍流水线

| 遍 | `backtest` | 用途 |
|---|---|---|
| 第 1 遍 | `True` | 取**样本外评估指标**（用于结果页四项指标） |
| 第 2 遍 | `False` | 取**未来预测值**（用于预测曲线） |

> 📌 两遍**不可合并**：评估需要真实值对比（必须砍末尾），预测需要输出未来（必须包含末尾）。
> 合并任一遍都会让"指标"或"预测值"之一失真。

## 4. 指标口径参数

| 参数 | 口径 | 备注 |
|---|---|---|
| **主指标** | **销量加权 MAPE** = `Σ\|e\| / Σ\|y\|`（即 WAPE） | 📌 `Q2` 已确认；不是"每序列 MAPE 再平均" |
| **辅指标** | **达标序列占比 ≥ 60%** | 单序列 MAPE ≤ 20% 视为达标 |
| **基线** | **移动平均**（moving average） | 🔒 相同预测点、相同序列集合 |
| MAE 上限基准 | 基线 MAE 的 85%（即至少降低 15%） | 任务书指标 |
| RMSE 上限基准 | 基线 RMSE 的 85%（即至少降低 15%） | 任务书指标 |
| MAPE 上限 | **20%** | 任务书指标 |
| 超标警告 | 结果页出现**不可折叠**的警告（`is_over_threshold`） | 🔒 `FR-VIS-*` / `EP-6` 断言 |
| 分布披露 | 中位数 / P75 / P90 / 最大值 / 超限条数 | `lstm_v1.report.json` 的 `distribution` |

### 4.1 ⏱️ 实测达成值

| 指标 | 实测 | 阈值 | 余量 |
|---|---|---|---|
| 加权 MAPE | **14.26%** | ≤ 20% | 5.74 pp |
| MAE 改善 | **26.42%** | ≥ 15% | +11.42 pp |
| RMSE 改善 | **27.52%** | ≥ 15% | +12.52 pp |
| 达标序列占比 | **83.95%**（68/81） | ≥ 60% | +23.95 pp |

### 4.2 覆盖率披露

| 项 | 实测（示例数据集） |
|---|---|
| `L1` | 81（71.68%） |
| `L2` | 32（28.32%） |
| `L3` | 0（0.00%） |
| `total` | 113 |
| `predictable` | 113（100%）—— L3 为 0 故全部可预测 |

> 🔒 `L1 + L2 + L3 = total`（断言项）。覆盖率取 `tasks` 表冗余列，不二次聚合。

### 11.3 运行纪律

| 纪律 | 原因 |
|---|---|
| 🔒 **每个校验脚本单独占一条命令** | 平台批量删除保护按**单次调用的累计删除数**计（阈值 50）；串跑会让后续脚本"假失败" |
| 🔒 断言不许放宽 | 放宽（如 `n ≥ 2`）等于自己削弱证据强度，**比不修更糟** |
| 🔒 断言失败必须打印实际值 | 否则失败时等于没给线索 |
| 🔒 不得把"未测"写成"通过" | 本项目 Safari 在 Windows 无发行版 → 如实登记 `BLOCKED` |

## 14. 边界与限制（如实披露）

| # | 限制 | 说明 / 现状 |
|---|---|---|
| 1 | **Safari 未实测** | Windows 无 Safari 发行版 → 登记为 `BLOCKED`（**不是"没测"，是"测不了"**）；Edge / Chrome / Firefox 各 109/109 |
| 2 | **极限规模走软失败** | 1000 序列 × h=30 实测 250.3 s → `E_TIMEOUT`。这是**正确的软失败**（无 5xx、无半成品），但**不是性能达标**（`P1-02`） |
| 3 | **在线重训练不提供** | 📌 决策；理由为 SLA 而非显存（⏱️ 峰值显存仅 111 MB） |
| 4 | **限流为单进程内存实现** | 故 `--workers` 固定为 1；改多进程**必须**先升级为共享存储（`TQ-2` 未引入 Redis） |
| 5 | **无自动化迁移工具** | 靠 `PRAGMA user_version` 手工管理（`TD-DB-03`） |
| 6 | **L2 序列精度有限** | 实测 L2 MAPE ≈ 60%（规则兜底 + 占比分摊），故主指标只统计 L1 |
| 7 | **预测误差随步长增长** | 预测区间上限 30 天 |
| 8 | **不适用于新品与突发冲击** | 见任务书 §6.3；结果页有显式声明 |
| 9 | **`metrics.baseline_mape` 恒 `NULL`** | 预留列，算法不产出（`TD-DB-04`） |
| 10 | **`metrics.l2_mape` 可能为 `NaN`** | 无 L2 序列时（`TQ-16` 待定是否在 `eval_note` 说明） |
| 11 | **演示数据为合成数据** | 由 `make_demo_data.py` 可复现生成；真实数据事实见 `RC-MET-04` |
| 12 | **游客数据 24 小时后清理** | 游客任务不可长期保存（`TQ-15`） |
